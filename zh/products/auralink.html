AuraLink Studio / AuraLink Router

运行中 · v0.9.0 · Windows

一台声卡，
整台电脑共用。

平时一开 DAW，其他应用就没声了。AuraLink Router 解决的正是这件事：DAW、系统声音、浏览器、OBS 同时跑在一台声卡上 —— 然后由你拉线决定每一路声音去哪里。它接替了已停止开发的 ASIO Link Pro。

核心功能

现在就能做到的。

以下每一条都经过实测，而非承诺。

  • 多个应用，一台声卡三个应用同时共用一台设备，各自设定各自的延迟，不掉音。
  • 4 条虚拟线缆在应用之间双向送声，每一路互不串扰。
  • DAW + 系统声音 → OBS音乐和系统声音同时进入 OBS，可用于直播或录制。
  • 拉线即可走声每个接口独立调音量和静音，8 个预设槽位，换场景一键切换。
  • 会用 ASIO Link Pro 就会用它声音的走法和 ALP 一样 —— 不需要重新学。
  • 配合 Cubase / Nuendo在 256 采样延迟下经耳听确认。
背景

AuraLink 为何存在。

ASIO Link Pro 是 Windows 上同类工具中最好的，且无可替代 —— 作者 John Shield 离世后，软件便停止了更新。它在功能上依然领先，只输在无人能维护的陈旧界面上。AuraLink 正是接下这个赌注：功能对齐到每一处，并给它一个人人可读的界面。
